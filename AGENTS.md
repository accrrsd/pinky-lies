# Project Rules and Code Style

These rules are mandatory for all AI agents when generating, refactoring, and editing code in this project.

## Code Style & Formatting

1. **Indentation**:
   - Use **2 spaces** for indentation across all files in the project (no tabs, no 4 spaces).

2. **Single-line Functions and Conditions**:
   - Functions, conditions (`if`, guard clauses, etc.), and control flows that can fit on a single line **must be written on a single line**.

3. **Class Declaration Order**:
   - In GDScript files, `class_name` must always be placed **after** `extends` (never above it).
